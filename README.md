# OTT Streaming Content Trend Analysis 🎬📊

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on streaming platform catalogs (Netflix, Amazon Prime, Hulu) to discover trends in content types, genres, release years, ratings, and country-wise distributions. The aim is to provide data-driven insights for content acquisition and strategy teams.

---

## 🛠️ Tools & Technologies Used
* **Python**: Pandas, NumPy, Matplotlib, Seaborn
* **SQL**: Aggregations, Grouping, Trend Analysis
* **Excel**: Data Cleaning, Pivots & Initial Analysis

---

## 💡 Key Analysis & Insights
1. **Movies vs. TV Shows**: Analyzed the proportion of movies and TV series available on the platform.
2. **Genre Trends**: Identified top-performing genres across global markets.
3. **Rating Distribution**: Categorized content by age ratings (TV-MA, PG-13, TV-14) to understand target audience focus.
4. **Release Timeline**: Tracked content addition trends across release years.
